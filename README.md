## Publicar no GitHub Pages
1. Crie um repositório público chamado `seuusuario.github.io` (ou qualquer nome).
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
4. Em 1–2 minutos o site fica no ar em `https://seuusuario.github.io`.

Também funciona na Vercel: importe o repositório e publique sem configuração.
